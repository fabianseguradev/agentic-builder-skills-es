# Free Skills (Traducción al Español)

55 skills gratuitos de Claude Code para principiantes.

Cada skill vive en su propia carpeta. Toma el que quieras, ponlo en tu directorio de skills de Claude Code y empieza a usarlo. Eso es toda la instalación.

Sin claves de API. Sin instalaciones. Sin scripts que ejecutar. Si tienes Claude Code, esto funciona.

## ¿Es este el repo correcto para ti?

**Sí, si eres nuevo.** Todo aquí funciona en el momento en que sueltas la carpeta. Sin claves de API, sin instalaciones, sin cuentas que configurar. Estos skills te enseñan Claude Code, hacen que tus primeras cosas se construyan y salgan en línea, y te ayudan a contarle a la gente sobre ellas.

**Cuando superes esto, vas a querer un set más pesado.** Pipelines de contenido completos, generación de video y miniaturas, renderizado de carruseles, automatizaciones de publicación, constructores de sitios. Ese tipo de skills hacen más, pero necesitan claves de API, herramientas conectadas y algo de configuración. Empieza aquí, ve allá cuando la versión simple deje de alcanzar.

## Empieza aquí

Ejecuta [`personalize`](./personalize) primero. Te hace algunas preguntas sobre tu nombre, tu nicho, tu oferta y tu audiencia, y luego guarda las respuestas en `~/.claude/brand-profile.md`.

Muchos de estos skills leen ese archivo. Así es como escriben con tu voz, para tu audiencia, sin que tengas que volver a explicarte cada vez. Solo lo haces una vez.

Luego ejecuta [`claude-orientation`](./claude-orientation) para elegir tu primer proyecto y anotar el siguiente movimiento de esta noche.

## Un orden sugerido

Si quieres un camino en lugar de un menú:

**Semana 1 — configúrate y lanza algo**

1. `/personalize` — configura tu perfil
2. `/claude-orientation` — elige UN proyecto
3. `/safety-net` — aprende los dos botones de deshacer para dejar de tener cuidado
4. `/first-website` o `/simple-game` — construye la cosa
5. `/deploy-it` — ponla en una URL real y mándasela a una persona

**Semana 2 — hazla buena y cuéntale a la gente**

6. `/design-taste` — escribe un estilo que sea tuyo
7. `/make-it-designed` y `/mobile-check` — púlela
8. `/caption-writer` — publica sobre ella

**Semana 3 — conviértela en dinero**

9. `/offer-builder` — construye algo que valga la pena vender
10. `/pricing-calculator` — ponle un número real
11. `/warm-outreach` y luego `/dm-writer` — encuentra a las primeras personas a las que contarles
12. `/first-customer-closer` y `/objection-handler` — ten la conversación

Luego `/session-wrapup` al final de cada noche y `/weekly-review` los domingos, para que nada se pierda.

## Cómo instalar un skill

Un skill es solo una carpeta con un `SKILL.md` adentro. Para instalar uno:

1. Descarga la carpeta del skill que quieras (mira [Descargar una sola carpeta](#descargar-una-sola-carpeta) abajo).
2. Muévela a tu directorio de skills de Claude Code:
   - **Personal (todos los proyectos):** `~/.claude/skills/`
   - **Solo un proyecto:** `.claude/skills/` dentro del proyecto
3. Reinicia Claude Code (o empieza una nueva sesión).
4. El skill ya está activo. Invócalo escribiendo `/` seguido del nombre del skill, por ejemplo `/personalize`.

Tu carpeta debería terminar viéndose así:

```
~/.claude/skills/
└── personalize/
    └── SKILL.md
```

## Descargar una sola carpeta

No tienes que clonar todo el repo. Algunas formas fáciles de conseguir solo una carpeta:

**Opción A — clona una vez, copia lo que quieras**

```bash
git clone https://github.com/fabianseguradev/agentic-builder-skills-es.git
cp -r agentic-builder-skills-es/personalize ~/.claude/skills/
```

**Opción B — instala las 55 de una vez**

```bash
git clone https://github.com/fabianseguradev/agentic-builder-skills-es.git
cd agentic-builder-skills-es
for d in */; do cp -r "$d" ~/.claude/skills/; done
```

**Opción C — descarga todo el repo como ZIP**

Haz clic en el botón verde **Code** en la página del repo, elige **Download ZIP**, descomprímelo y copia la carpeta que quieras a `~/.claude/skills/`.
