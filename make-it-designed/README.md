# Make It Designed

Apúntalo a una página que ya construiste y convierte "funciona pero se ve por defecto" en "se ve diseñada" — sin reconstruir nada.

La mayoría de la gente intenta arreglar una página fea agregando: otro color, otra sección, otro ícono. Esa es la causa, no la cura. Este skill **quita tres cosas antes de agregar una**, aplica una lista fija sobre tipografía, espaciado, color y jerarquía, y luego agrega exactamente un detalle distintivo para que la página tenga un punto de vista.

## Instalación

1. Copia la carpeta `make-it-designed` en tu directorio de skills de Claude Code:
   ```bash
   cp -r make-it-designed ~/.claude/skills/
   ```
2. Reinicia Claude Code (o empieza una nueva sesión).
3. Invócalo escribiendo `/make-it-designed`.

## Cómo usarlo

No necesita configuración. Escribe `/make-it-designed` y dale la ruta de tu página. Lee el archivo, te muestra qué está recortando y por qué, arregla la combinación de fuentes y los saltos de tamaño, ajusta cada espacio a una escala de espaciado real, reduce la paleta a cinco colores y agrega un toque distintivo — un subrayado dibujado a mano, un titular editorial o una franja de datos.

Tu contenido y tus links nunca se mueven. Si lo odias, escribe `/rewind`. También escribe un registro de cambios corto en `~/design-notes/` para que veas qué cambió.
