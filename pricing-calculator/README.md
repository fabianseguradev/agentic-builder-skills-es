# Pricing Calculator

Consigue un precio basado en lo que vale el resultado para tu comprador, no en cuánto tiempo te tomó hacerlo.

La mayoría de la gente cobra de menos porque pone el precio según el esfuerzo. "Solo me tomó un fin de semana" es como un proyecto que le hace ganar $20,000 a un cliente termina siendo un trabajo de $300. La solución es **ponerle primero un número en dólares al resultado** y luego cobrar una fracción segura de él, para que el comprador siga obteniendo un retorno obvio.

## Instalación

1. Copia la carpeta `pricing-calculator` en tu directorio de skills de Claude Code:
   ```bash
   cp -r pricing-calculator ~/.claude/skills/
   ```
2. Reinicia Claude Code (o empieza una nueva sesión).
3. Invócalo escribiendo `/pricing-calculator`.

## Cómo usarlo

Escribe `/pricing-calculator`. Lee tu perfil de marca en `~/.claude/brand-profile.md`, así que ejecuta `/personalize` primero si no lo has hecho. Calcula cuánto vale tu oferta para el comprador en dinero ganado, dinero ahorrado, tiempo ahorrado o dolor evitado, fija un precio a partir de ese número, arma niveles bueno/mejor/el mejor, pone el precio a prueba contra las objeciones habituales y elige una estructura de pago.

Obtienes las cuentas del valor, un precio recomendado, la tabla de niveles y algunas líneas que puedes decir en voz alta en una llamada, guardado en `~/offers/pricing.md`.
