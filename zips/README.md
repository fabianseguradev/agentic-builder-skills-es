# Descargas de un clic

Cada skill de este repo, comprimido, para que puedas conseguir uno sin clonar nada.

Descarga el zip del skill que quieras, descomprímelo en tu carpeta `~/.claude/skills/`, y en Claude Code simplemente di "usa <nombre-del-skill> en esto".

Cada zip contiene el `SKILL.md` y el `README.md` de ese skill (y sus archivos de referencia, si tiene).
