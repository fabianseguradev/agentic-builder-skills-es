# First-Customer Closer

Alguien está interesado y no sabes qué decir. Esto te da un guion de ventas de una página para esa conversación exacta.

Hecho para gente que odia vender. El cambio de enfoque sobre el que funciona: **una conversación de ventas es simplemente ayudar a alguien a tener claro si esto es lo correcto para él.** Haces preguntas honestas, escuchas y, si encaja, haces que sea fácil decir que sí. Si no encaja, lo dices. El guion sigue el marco CLOSER — aclarar, nombrar, repasar, vender el resultado, disipar preocupaciones, reforzar.

## Instalación

1. Copia la carpeta `first-customer-closer` en tu directorio de skills de Claude Code:
   ```bash
   cp -r first-customer-closer ~/.claude/skills/
   ```
2. Reinicia Claude Code (o empieza una nueva sesión).
3. Invócalo escribiendo `/first-customer-closer`.

## Cómo usarlo

Escribe `/first-customer-closer` y dile quién es el prospecto, cómo llegó a ti y si es una llamada en vivo o una conversación por DM. Escribe las seis etapas de CLOSER con las palabras exactas que decir, una lista corta de preguntas para hacer, la línea que invita a la venta y una respuesta para el "déjame pensarlo". El guion se guarda en `~/first-customer-script.md`. Léelo en voz alta una vez antes de la conversación.

Lee tu perfil de marca en `~/.claude/brand-profile.md` para escribir con tu voz. Si todavía no lo configuraste, ejecuta `/personalize` primero.
