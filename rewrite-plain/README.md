# Rewrite Plain

Reescribe cualquier cosa en un lenguaje simple y directo que una persona ocupada entiende en la primera lectura.

La escritura poco clara normalmente no es un problema de vocabulario — es un rodeo, o un preámbulo de tres oraciones antes de que alguien diga algo. Esto lo quita y deja tu significado exactamente donde estaba. **Una pasada de claridad, no una reescritura de tu argumento**: los mismos hechos, la misma postura, dichos para que peguen.

## Instalación

1. Copia la carpeta `rewrite-plain` en tu directorio de skills de Claude Code:
   ```bash
   cp -r rewrite-plain ~/.claude/skills/
   ```
2. Reinicia Claude Code (o empieza una nueva sesión).
3. Invócalo escribiendo `/rewrite-plain`.

## Cómo usarlo

Ejecuta `/personalize` primero para que la reescritura siga sonando a ti y no a una plantilla. Luego escribe `/rewrite-plain` y pega el texto, o dale una ruta de archivo. Funciona en emails, posts, bios, páginas de ventas, documentos.

Hace una pregunta — quién lee esto y qué debería hacer — y luego corta el calentamiento, los rodeos, las evasivas en pasiva y las palabras corporativas que no significan nada. Obtienes una versión limpia lista para pegar, el conteo de palabras antes y después, y de tres a cinco pares de antes/después de tu propio texto para que empieces a notar el patrón tú mismo. Guardado en `~/rewrites/`, con tu original conservado al final.
