# Claude Orientation

Instalaste Claude Code y no sabes qué construir. Esto te dice lo único que debes construir primero y qué hacer esta noche.

Los principiantes no fracasan por falta de ideas. Fracasan por tener cinco y no terminar ninguna. Este skill te ubica en un arco de 9 etapas — instalación, memoria, sitio web, landing page, skills, juego, agentes, contenido, distribución — y luego **recorta tu lista a un solo proyecto** y escribe el único siguiente paso de esta noche en un archivo que vuelves a abrir en cada sesión.

## Instalación

1. Copia la carpeta `claude-orientation` en tu directorio de skills de Claude Code:
   ```bash
   cp -r claude-orientation ~/.claude/skills/
   ```
2. Reinicia Claude Code (o empieza una nueva sesión).
3. Invócalo escribiendo `/claude-orientation`.

## Cómo usarlo

No necesita configuración. Escribe `/claude-orientation` y responde dos preguntas: qué etapas has terminado de verdad, y todos los proyectos en los que estás pensando ahora mismo. Elige tu etapa, recorta tu lista de proyectos a uno, encoge ese uno hasta que pueda salir en cinco noches y estaciona el resto para que nada se sienta perdido.

Obtienes `~/claude-roadmap.md` con tu etapa, tu único proyecto, cinco noches de pasos de una línea, un arco de 30 días y las palabras exactas para pegar en Claude esta noche. Abre ese archivo al inicio de cada sesión y reescribe la línea del siguiente paso antes de cerrar la laptop.
