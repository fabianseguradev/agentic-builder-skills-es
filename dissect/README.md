# Dissect

Pega un post que esté funcionando y recibe por qué funciona — el gancho, la estructura, el formato, el motor de interacción — más un brief para construir tu propia versión.

Copiar un post viral no te da nada, porque el tema no es lo que lo hizo funcionar. **Lo que se transfiere es el mecanismo.** Este skill separa las dos cosas: nombra la maquinaria de fondo para que puedas hacerla funcionar con tu propio tema, para tu propia audiencia.

## Instalación

1. Copia la carpeta `dissect` en tu directorio de skills de Claude Code:
   ```bash
   cp -r dissect ~/.claude/skills/
   ```
2. Reinicia Claude Code (o empieza una nueva sesión).
3. Invócalo escribiendo `/dissect`.

## Cómo usarlo

No necesita configuración. Nada que configurar, ningún perfil que completar primero.

Pega un post de LinkedIn, el caption de un Reel, el gancho de un video de YouTube o un hilo de Reddit — pega el texto en sí, no un link. Recibes seis secciones: mecanismo del gancho, patrón de estructura, formato, motor de interacción, tres cosas que vale la pena robar y un brief de recreación con la primera línea de tu versión ya escrita.
