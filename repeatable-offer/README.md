# Repeatable Offer

Convierte el servicio que sigues haciendo a medida en una sola cosa fija que puedes vender una y otra vez.

El trabajo a medida agota porque cada venta empieza en cero. Vuelves a explicar qué haces, adivinas un precio y luego el proyecto crece más allá de lo acordado. Este skill encuentra **la parte del trabajo que es igual en cada proyecto**, le pone un marco alrededor y le da a ese marco un nombre, un precio, un plazo y una checklist que sigues cada vez.

## Instalación

1. Copia la carpeta `repeatable-offer` en tu directorio de skills de Claude Code:
   ```bash
   cp -r repeatable-offer ~/.claude/skills/
   ```
2. Reinicia Claude Code (o empieza una nueva sesión).
3. Invócalo escribiendo `/repeatable-offer`.

## Cómo usarlo

Ejecuta `/personalize` una vez primero para que conozca tu nicho, tu oferta y tu audiencia. Luego escribe `/repeatable-offer`.

Te guía por los últimos trabajos que hiciste y encuentra qué se repitió, y luego te hace convertir eso en un solo entregable con una línea de meta real. La parte difícil es el paso 4, donde escribes qué NO está incluido, porque eso es lo que evita que el trabajo crezca en silencio. Terminas con un nombre, una promesa de una línea, un precio fijo y la checklist de entrega que sigues en cada pedido.

Obtienes una oferta de una página guardada en `~/offers/<product-name>.md`. Funciona como la página que le envías a un comprador y como la checklist que sigues mientras entregas.
