# Explain This

Pega cualquier archivo, carpeta, fragmento o configuración que no reconozcas y recibe una explicación en lenguaje simple escrita para alguien que nunca ha programado.

Tu proyecto se llena de archivos que nunca creaste, y empieza a sentirse como la máquina de otra persona. Este skill responde las cinco preguntas que de verdad tienes — qué es, qué hace, por qué está aquí, **qué pasaría si desapareciera** y qué partes cambiarías de forma realista — y cierra con una cosa que vale la pena entender y una cosa que tienes permiso para ignorar para siempre.

## Instalación

1. Copia la carpeta `explain-this` en tu directorio de skills de Claude Code:
   ```bash
   cp -r explain-this ~/.claude/skills/
   ```
2. Reinicia Claude Code (o empieza una nueva sesión).
3. Invócalo escribiendo `/explain-this`.

## Cómo usarlo

No necesita configuración. Escribe `/explain-this` y pega lo que te confunde, o simplemente nombra el archivo y deja que lo lea. Un archivo entero, un listado de carpeta, cinco líneas, una palabra que viste — todo sirve. No necesitas hacer una pregunta; asume que la pregunta es "qué es esto y debería importarme".

Recibes la explicación guardada en `~/claude-explained/`, que poco a poco se convierte en un glosario de tu propio proyecto con tus propias palabras. No hay nada que hacer después — este es para leer.
