# Objection Handler

Una hoja de referencia con respuestas tranquilas y honestas a las objeciones que de verdad escuchas — escritas para tu oferta, con tu voz.

**Una objeción no es un rechazo.** Es una preocupación real que alguien necesita que le respondan antes de poder decir que sí. La mayoría de la gente o cede al instante o se pone a la defensiva, y ambas cosas pierden la venta. Cada respuesta aquí sigue la misma forma: reconocer, reencuadrar, dar una razón verdadera por la que se sostiene y luego invitar a un pequeño siguiente paso. Nada inventado, sin presión.

## Instalación

1. Copia la carpeta `objection-handler` en tu directorio de skills de Claude Code:
   ```bash
   cp -r objection-handler ~/.claude/skills/
   ```
2. Reinicia Claude Code (o empieza una nueva sesión).
3. Invócalo escribiendo `/objection-handler`.

## Cómo usarlo

Escribe `/objection-handler`. Empieza por las cuatro que escucha todo el mundo — demasiado caro, no tengo tiempo, déjame pensarlo, ¿funciona para alguien como yo? — y luego te pregunta cuáles recibes de verdad y qué más aparece. Obtienes una respuesta completa para cada una más una versión de una línea lo bastante corta para mandarla por DM, un recordatorio de hacer una pregunta antes de responder y una forma cálida de salir cuando de verdad es un no. Todo se guarda en `~/objection-cheatsheet.md`.

Lee tu perfil de marca en `~/.claude/brand-profile.md` para escribir con tu voz. Si todavía no lo configuraste, ejecuta `/personalize` primero.
