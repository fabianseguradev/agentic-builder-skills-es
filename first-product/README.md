# First Product

Convierte lo que ya sabes en una guía digital terminada que puedes vender, escrita de principio a fin en una sola sentada.

La mayoría de la gente nunca vende nada porque está esperando construir la gran cosa. **Un primer producto es pequeño a propósito.** Una guía, un lector, un resultado, vendida a un precio bajo. Este skill te entrevista sobre tu ángulo y tus lecciones, y luego escribe las 20 a 40 páginas reales, no un esquema de ellas.

## Instalación

1. Copia la carpeta `first-product` en tu directorio de skills de Claude Code:
   ```bash
   cp -r first-product ~/.claude/skills/
   ```
2. Reinicia Claude Code (o empieza una nueva sesión).
3. Invócalo escribiendo `/first-product`.

## Cómo usarlo

Ejecuta `/personalize` una vez primero para que conozca tu nicho, tu audiencia y tu oferta. Luego escribe `/first-product`.

Te hace cuatro preguntas: tu ángulo, las tres a cinco cosas que le enseñarías a alguien desde cero, una muestra de escritura para que suene a ti y cuánto quieres cobrar. Te muestra una lista de capítulos, dices que sí y luego escribe la guía completa.

Terminas con dos archivos en `~/guides/<your-guide>/`. `guide.md` es la guía en sí, con un formato que se convierte a PDF de forma limpia. `listing.md` es el texto para la página de tu producto (título, pitch, precio, tres viñetas) más una lista honesta del puñado de cosas que todavía tienes que hacer tú, como crear la cuenta de la tienda y subir el archivo.
