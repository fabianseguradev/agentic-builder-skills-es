# Case Study

Convierte un logro en un texto corto que puedes enviar a un prospecto o publicar.

Un proyecto terminado guardado en una carpeta no hace nada por ti. Este skill lo convierte en una página construida sobre un antes y un después reales: dónde empezaron y qué les estaba costando, qué construiste, qué cambió y **una línea honesta sobre la parte difícil** — que es la sección que la gente corta, y la que hace creíble el resto.

## Instalación

1. Copia la carpeta `case-study` en tu directorio de skills de Claude Code:
   ```bash
   cp -r case-study ~/.claude/skills/
   ```
2. Reinicia Claude Code (o empieza una nueva sesión).
3. Invócalo escribiendo `/case-study`.

## Cómo usarlo

Ejecuta `/personalize` una vez primero. Luego escribe `/case-study` y di qué construiste y para quién — un cliente que pagó, un favor gratis o tu propio proyecto funcionan igual.

Te entrevista como corresponde, insistiendo en los detalles concretos que la mayoría deja fuera, y no inventará una métrica. Si no hay un número, usa en su lugar una descripción concreta del antes/después, que se lee igual de bien. Obtienes dos versiones — una ajustada para un DM y una más larga para LinkedIn o un portafolio — guardadas en `~/case-studies/`.
