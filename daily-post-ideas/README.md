# Ideas diarias de posts de LinkedIn

Cinco ideas de posts de LinkedIn para hoy, cada una con una línea de gancho que puedes pegar directamente y una línea sobre hacia dónde va el post.

Las cinco ideas nunca son cinco versiones de lo mismo. Cada una sale de una categoría distinta — Lección, Opinión Polémica, Historia, Consejo de Herramienta, Atracción de Comunidad — así cubres distintas razones por las que alguien deja de scrollear. **Los ganchos usan las propias palabras de tu audiencia**, tomadas de tu perfil, no lenguaje de marketing.

## Instalación

1. Copia la carpeta `daily-post-ideas` en tu directorio de skills de Claude Code:
   ```bash
   cp -r daily-post-ideas ~/.claude/skills/
   ```
2. Reinicia Claude Code (o empieza una nueva sesión).
3. Invócalo escribiendo `/daily-post-ideas`.

## Cómo usarlo

Lee tu perfil de marca en `~/.claude/brand-profile.md`, así que ejecuta `/personalize` primero si no lo has hecho. De ahí salen tu audiencia, tu oferta, tu prueba y tu tono.

Escribe `/daily-post-ideas`. No necesitas tema, ni búsqueda web, ni ninguna otra información. Recibes cinco ideas numeradas. Elige una y di "escríbelo" para que se redacte el post completo.
