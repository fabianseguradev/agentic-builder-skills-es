# Positioning Filter

Fija el único ángulo que hace que suenes a ti en lugar de a todos los demás en tu nicho.

La mayoría de las ofertas no fracasan porque sean malas. Fracasan porque nadie puede distinguirlas. Este skill aplica tres preguntas y una prueba de recorte para forzar un ángulo único y defendible. La prueba de recorte es la parte que la gente se salta: **te define tanto lo que te niegas a ser** como lo que afirmas.

## Instalación

1. Copia la carpeta `positioning-filter` en tu directorio de skills de Claude Code:
   ```bash
   cp -r positioning-filter ~/.claude/skills/
   ```
2. Reinicia Claude Code (o empieza una nueva sesión).
3. Invócalo escribiendo `/positioning-filter`.

## Cómo usarlo

Escribe `/positioning-filter`. Lee tu perfil de marca en `~/.claude/brand-profile.md`, así que ejecuta `/personalize` primero si no lo has hecho. Te pregunta qué dices tú que tu nicho no dice, por qué le importaría a tu audiencia y cómo ese ángulo apunta a lo que vendes. Luego te hace recortar: para quién no es esto, de qué temas no vas a hablar y qué coberturas soltar.

Obtienes una declaración de posicionamiento y un diferenciador de una línea guardados en `~/offers/positioning.md`. Pega la frase de una línea en tu bio y reutiliza la declaración en cualquier página de ventas.
